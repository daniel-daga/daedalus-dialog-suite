Dandelion

Daedalus Dialog Editor for Gothic 2

An Electron editor for Daedalus scripts and ZenGin worlds. Scripts are parsed with a Tree-sitter grammar into a semantic model and written back in place. The download is the newest master build.

What's new

    What it edits

    Dialogs

    Dialog instances and their functions: lines, choice branches, conditions and actions. A simulator steps through them.

    C_INFOAI_OutputInfo_AddChoice

    Quests

    Quest state variables and diary entries, cross-referenced to the dialogs that set them.

    MIS_Log_CreateTopicB_LogEntry

    NPCs and routines

    Instance bodies (attributes, talents, equipment, visuals) with a bind-pose preview; daily routines edited against the waynet.

    C_NPCRtn_TA_

    Worlds

    ZenGin worlds through a ZenKit N-API binding in a three.js viewport: VOB properties, hierarchy and waynet. Saves are round-trip tested.

    .zenzCVobzCWayNet

    Problems

    Parser syntax errors plus rule checks over the project index: dangling info checks, overlapping routines, waypoints missing from the world.

    Npc_KnowsInfoWld_InsertNpc

    Source-preserving saves

    Edits are patched into the original text: comments, blank lines and expressions stay as written, in the file's original encoding.

    Tree-sitterWindows-1252

    Build details

    Package
    NSIS installer for Windows, unsigned
    Source
    Built by GitHub Actions from master after the full test matrix passes
    Updates
    Checked in the app against update-meta.json; the installer is SHA-256 verified before it runs
    Projects
    Open a mod's scripts folder; it is indexed in the background and watched for outside edits
